# Engineering Governance — agent entrypoint

Before changing this repository:
1. Read `GLOBAL-ENGINEERING-RULES.md` completely.
2. Check current main/PRs/branches/workflows.
3. Use Issues #1–#4 for the current bootstrap/adoption workflow while active.
4. Use a dedicated branch for each package.
5. Governance changes require changelog/version updates.
6. This repository contains policy/templates only; it must never become a product-deploy trigger.

The canonical global policy is `GLOBAL-ENGINEERING-RULES.md`.
