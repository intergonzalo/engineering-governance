# Public Engineering Portfolio

This directory contains **curated, public-safe engineering case studies** for products whose production source repositories remain private.

The goal is to show product thinking, architecture, engineering discipline and selected implementation patterns without publishing proprietary source code or creating an attack map.

## Projects

- [TMJ Securitizadora](./tmj-securitizadora/) — financial operations platform built around Firebase, role-specific web surfaces, document workflows, operational queues and selective CI/CD.
- Tallerito — automotive workshop SaaS. Public case study added as a separate package.

## Publication model

These are **not mirrors** of the private repositories.

Public material may include:
- high-level architecture;
- product/engineering challenges and outcomes;
- sanitized diagrams;
- synthetic or rewritten code examples that demonstrate an engineering pattern.

Public material intentionally excludes:
- production source files copied verbatim;
- credentials, tokens, runtime configuration and private endpoints;
- customer, investor, workshop or transaction data;
- proprietary financial, credit, pricing or contract logic;
- database schemas, security rules and authorization internals;
- infrastructure identifiers that would unnecessarily increase attack surface.

The private repositories remain the canonical implementation sources.
